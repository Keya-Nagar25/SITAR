    INSAT-3DS TIR1 at 15-minute cadence

    INSAT-3DS images the full disk every 30 minutes. The model trained on GOES-19 / Himawari fills in the frame between each pair. The left track holds each native frame until the next one arrives, so you can see the gaps the model fills.

    Hold-out check

    INSAT has no real 15-minute frames to compare against. As a check, we take frames 60 minutes apart, predict the native 30-minute frame between them and score it. This test is harder than the real 30→15 job.
